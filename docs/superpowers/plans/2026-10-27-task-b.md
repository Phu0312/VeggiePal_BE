# Task B (seed tác giả + kiểm duyệt blog bất đồng bộ) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking. Agents without these skills: execute the tasks in order, one at a time, TDD as written, and stop at each task's "Bàn giao" step.

**Goal:**
- identity-service seed ba tác giả (id 1–3) mà dữ liệu seed của blog-service trỏ tới.
- Kiểm duyệt AI cho blog chạy nền (US12). Bài bị ẩn ở `PENDING` cho tới khi AI duyệt, AI sập thì có job retry, và kiểm duyệt không tính vào quota AI của user.

**Architecture:**
- `data.sql` mới trong identity-service.
- ai-service thêm `POST /internal/moderation/check`, xác thực bằng `X-Internal-Service-Token` và không gọi `checkBudget`. `AiContentModerationService` của blog-service gọi endpoint này thay cho endpoint dùng JWT user.
- `BlogService` không gọi AI nữa: nó đặt `PENDING` + `moderation_requested_at` rồi phát `BlogModerationRequested`.
- `BlogModerationWorker` (`@Async` + `@TransactionalEventListener(AFTER_COMMIT)`) gọi AI ngoài mọi transaction và trả kết quả về `BlogService.applyAiModeration`. Một job `@Scheduled` retry các bài bị kẹt.

**Tech Stack:** Java 21, Spring Boot 4.1.1 (Spring Framework 7), Spring Data JPA, MySQL 8, Lombok, MapStruct, JUnit 5 + Mockito + AssertJ, Awaitility 4.3.0 (đã có sẵn qua `spring-boot-starter-test`).

**Spec:** [`docs/superpowers/specs/2026-10-27-task-b-design.md`](../specs/2026-10-27-task-b-design.md)

**Bổ sung sau review đã được Long duyệt:** sau Task 1–7, thực hiện Task 8 ở cuối plan để bảo vệ guard áp kết quả AI bằng khóa hàng ngắn và test race MySQL. Task 8 sửa giả định ban đầu rằng guard trong bộ nhớ đủ an toàn khi có admin/owner cập nhật đồng thời. Nhánh bàn giao được Long chọn lại là `fix/recheck-curent-error`.

- **Không thêm dependency.**
- Style: `@RequiredArgsConstructor` + `@FieldDefaults(level = AccessLevel.PRIVATE, makeFinal = true)`, field khai báo trần (blog-service, identity-service). ai-service dùng `private final` + `@RequiredArgsConstructor`.

```java
package com.veggiepal.ai.security;

import com.veggiepal.ai.common.AppException;
import com.veggiepal.ai.common.ErrorCode;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

/** Copy of blog-service's class: checks the X-Internal-Service-Token header on service-to-service calls. */
@Component
public class InternalServiceToken {
    private final byte[] configured;

    public InternalServiceToken(@Value("${services.internal-token:}") String token) {
        configured = token == null ? new byte[0] : token.getBytes(StandardCharsets.UTF_8);
    }

    public void require(String supplied) {
        byte[] candidate = supplied == null ? new byte[0] : supplied.getBytes(StandardCharsets.UTF_8);
        if (configured.length == 0 || !MessageDigest.isEqual(configured, candidate)) {
            throw new AppException(ErrorCode.UNAUTHENTICATED);
        }
    }
}
```

```java
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestHeader;
import org.springframework.web.bind.annotation.RestController;

/**
 * blog-service's moderation entry point. Not routed by the gateway, which only forwards AI paths,
 * and guarded by the shared internal token rather than a user's JWT.
 */
@RestController @RequiredArgsConstructor
public class InternalModerationController {
    static final String INTERNAL_TOKEN_HEADER = "X-Internal-Service-Token";

    private final ModerationService service;
    private final InternalServiceToken tokens;

    @PostMapping("/internal/moderation/check")
    ApiResponse<ModerationResponse> check(
            @RequestHeader(name = INTERNAL_TOKEN_HEADER, required = false) String token,
            @RequestBody @Valid ModerationRequest request) {
        tokens.require(token);
        return ApiResponse.success(service.moderateForService(request));
    }
}
```

```java
package com.veggiepal.blog.moderation;

import com.veggiepal.blog.exception.AppException;
import com.veggiepal.blog.exception.ErrorCode;
import java.time.Duration;
import java.util.Map;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.http.client.SimpleClientHttpRequestFactory;
import org.springframework.stereotype.Service;
import org.springframework.web.client.RestClient;
import org.springframework.web.client.RestClientException;
// Jackson 3: Spring Boot 4's RestClient cannot deserialize into Jackson 2's com.fasterxml JsonNode.
import tools.jackson.databind.JsonNode;

@Service
public class AiContentModerationService implements ContentModerationService {

    static final String INTERNAL_TOKEN_HEADER = "X-Internal-Service-Token";

    private final RestClient client;
    private final String internalToken;

    public AiContentModerationService(
            @Value("${services.ai.base-url}") String baseUrl,
            @Value("${services.ai.connect-timeout:3s}") Duration connectTimeout,
            @Value("${services.ai.read-timeout:20s}") Duration readTimeout,
            @Value("${services.internal-token:}") String internalToken
    ) {
        var requestFactory = new SimpleClientHttpRequestFactory();
        requestFactory.setConnectTimeout(connectTimeout);
        requestFactory.setReadTimeout(readTimeout);
        this.client = RestClient.builder().baseUrl(baseUrl).requestFactory(requestFactory).build();
        this.internalToken = internalToken;
    }

    // The service token, not the caller's JWT: blog moderation runs on a background thread with
    // no request behind it, and moderation is a platform cost that must not eat the user's AI quota.
    @Override
    public ModerationResult moderate(
            String contentType,
            Long externalContentId,
            Long authorId,
            String text
    ) {
        try {
            JsonNode response = client.post()
                    .uri("/internal/moderation/check")
                    .header(INTERNAL_TOKEN_HEADER, internalToken)
                    .body(Map.of(
                            "contentType", contentType,
                            "externalContentId", externalContentId,
                            "authorId", authorId,
                            "text", text
                    ))
                    .retrieve()
                    .body(JsonNode.class);

            JsonNode result = response == null ? null : response.path("result");
            if (result == null || result.isMissingNode() || result.path("decision").asString().isBlank()) {
                throw new AppException(ErrorCode.INVALID_MODERATION_RESPONSE);
            }

            ModerationDecision decision;
            try {
                decision = ModerationDecision.valueOf(result.path("decision").asString());
            } catch (IllegalArgumentException exception) {
                throw new AppException(ErrorCode.INVALID_MODERATION_RESPONSE);
            }
            return new ModerationResult(decision, result.path("reason").asString(null));
        } catch (AppException exception) {
            throw exception;
        } catch (RestClientException exception) {
            throw new AppException(ErrorCode.MODERATION_UNAVAILABLE);
        }
    }
}
```

```java
     * BR-02 + task sheet US12: hide the post and let AI decide in the background
     * (BlogModerationWorker, once this transaction commits).
     */
    private void requestModeration(Blog blog) {

        blog.setStatus(ContentStatus.PENDING);
        blog.setModerationReason(null);
        blog.setModerationRequestedAt(LocalDateTime.now());

        eventPublisher.publishEvent(
                new BlogModerationRequested(blog.getId(), blog.getAuthorId(), moderationText(blog)));
    }

    /** What AI judges, and how a late verdict recognises it still applies. */
    public static String moderationText(Blog blog) {
        return blog.getTitle() + "\n" + blog.getContent();
    }

    /** Applies AI's verdict, unless the post moved on while AI was deciding. */
    @Transactional
    public void applyAiModeration(Long blogId, String moderatedText, ModerationResult result) {

        Blog blog = blogRepository.findById(blogId).orElse(null);

        // Deleted, banned or decided by an admin, already answered, or edited again since
        if (blog == null
                || blog.getStatus() != ContentStatus.PENDING
                || blog.getModerationRequestedAt() == null
                || !moderationText(blog).equals(moderatedText)) {
            return;
        }

        blog.setModerationRequestedAt(null);

        switch (result.decision()) {

            case APPROVED -> {
                blog.setStatus(ContentStatus.PUBLISHED);
                blog.setModerationReason(null);

                // Stamped once: re-publishing an edited post must not reshuffle the feed
                if (blog.getPublishedAt() == null) {
                    blog.setPublishedAt(LocalDateTime.now());
                }
            }

            case REJECTED -> {
                blog.setStatus(ContentStatus.REJECTED);
                blog.setModerationReason(result.reason());
            }

            // Stays PENDING; ai-service has queued the case for an admin
            case REVIEW_REQUIRED -> blog.setModerationReason(result.reason());
        }
    }
```

```java
package com.veggiepal.blog.moderation;

import java.time.Duration;
import java.time.LocalDateTime;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.scheduling.annotation.Async;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;
import org.springframework.transaction.event.TransactionPhase;
import org.springframework.transaction.event.TransactionalEventListener;

import com.veggiepal.blog.entity.Blog;
import com.veggiepal.blog.enums.ContentStatus;
import com.veggiepal.blog.exception.AppException;
import com.veggiepal.blog.repository.BlogRepository;
import com.veggiepal.blog.service.BlogService;

import lombok.extern.slf4j.Slf4j;

/**
 * Task sheet US12: blog moderation runs in the background. No transaction is open while
 * ai-service is called, so a slow AI can no longer hold database connections.
 */
@Component
@Slf4j
public class BlogModerationWorker {

    private final ContentModerationService contentModerationService;
    private final BlogService blogService;
    private final BlogRepository blogRepository;
    private final Duration retryInterval;

    public BlogModerationWorker(
            ContentModerationService contentModerationService,
            BlogService blogService,
            BlogRepository blogRepository,
            @Value("${moderation.retry-interval:PT2M}") Duration retryInterval
    ) {
        this.contentModerationService = contentModerationService;
        this.blogService = blogService;
        this.blogRepository = blogRepository;
        this.retryInterval = retryInterval;
    }

    @Async
    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
    public void onModerationRequested(BlogModerationRequested event) {
        moderate(event.blogId(), event.authorId(), event.text());
    }

    // ponytail: retries every interval for as long as AI stays down; add an attempt count or backoff if the backlog grows
    @Scheduled(
            fixedDelayString = "${moderation.retry-interval:PT2M}",
            initialDelayString = "${moderation.retry-interval:PT2M}"
    )
    public void retryStalled() {
        LocalDateTime cutoff = LocalDateTime.now().minus(retryInterval);
        for (Blog blog : blogRepository.findTop20ByStatusAndModerationRequestedAtBeforeOrderByModerationRequestedAtAsc(
                ContentStatus.PENDING, cutoff)) {
            moderate(blog.getId(), blog.getAuthorId(), BlogService.moderationText(blog));
        }
    }

    private void moderate(Long blogId, Long authorId, String text) {
        try {
            ModerationResult result = contentModerationService.moderate("BLOG", blogId, authorId, text);
            blogService.applyAiModeration(blogId, text, result);
        } catch (AppException exception) {
            // Left PENDING with moderation_requested_at set, so retryStalled picks it up
            log.warn("AI moderation of blog {} failed: {}", blogId, exception.getErrorCode());
        }
    }
}
```
